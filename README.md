# 2026 世界杯 · 竞猜 H5

一个**纯前端、移动端优先**的 2026 世界杯竞猜小应用，无需后端即可运行，数据使用浏览器 `localStorage` 持久化。

## 功能

- **首页赛程**：展示 2026 世界杯（美/加/墨）小组赛赛程，按日期分组、显示分组/比分/状态（未开赛 / 进行中 / 已结束），支持「全部 / 未开赛 / 我关注的」筛选。
- **用户注册 / 登录**：用户名 + 密码注册登录，登录态本地保存。
- **关注球队 → 自动生成看球日历**：在「关注」页选择喜欢的球队，「我的」页会自动汇总你关注球队的全部比赛，并支持一键导出 `.ics` 文件导入手机系统日历。
- **胜平负竞猜**：对所有**未开赛**的比赛投注（主胜 / 平局 / 客胜），开赛后锁定。
- **积分与积分榜**：比赛结束后自动结算，猜中一场 +3 分；积分榜对所有用户排名展示，并高亮当前用户。

## 运行

直接用浏览器打开 `index.html` 即可。若浏览器对本地文件有限制，可起一个静态服务：

```bash
cd worldcup2026-h5
python3 -m http.server 8080
# 打开 http://localhost:8080
```

建议用手机或浏览器的「移动设备模拟」模式查看（页面为 H5 竖屏布局）。

## 文件结构

```
worldcup2026-h5/
├── index.html   # 页面骨架 + 底部导航

```
