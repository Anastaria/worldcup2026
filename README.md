# 2026 世界杯 · 竞猜 H5

一个**纯前端、移动端优先**的 2026 美加墨世界杯竞猜小应用，无需后端即可运行，数据使用浏览器 `localStorage` 持久化。

> 赛程数据（分组、对阵、日期、北京时间开球时间、官方淘汰赛槽位）按**官方赛程**还原，来源参考百度体育。共 104 场（72 场小组赛 + 32 场淘汰赛），时间为北京时间。

## 功能

- **首页赛程**：展示 2026 世界杯（美/加/墨）完整 104 场赛程（72 场小组赛 + 32 场淘汰赛），按日期分组、显示分组/比分/状态（未开赛 / 进行中 / 已结束），支持「全部 / 小组赛 / 淘汰赛 / 未开赛 / 我关注的」筛选。
- **淘汰赛赛程**：1/16 → 1/8 → 1/4 → 半决赛 → 季军赛 → 决赛。对阵以"槽位"表示（如 `A组第1`、`1/16-1胜者`），并会**根据小组排名 / 上一轮结果自动推算出具体对阵球队**。对阵未确定时显示"待定"，确定后即可竞猜。
- **用户注册 / 登录**：用户名 + 密码注册登录，登录态本地保存。
- **感兴趣球队 + 专属赛程（无需登录）**：「关注」页分「我的赛程 / 选择球队」两个视图：**无需登录**即可选择感兴趣的球队（游客选择保存在本设备），「我的赛程」会自动汇总这些球队的全部比赛（小组赛 + 淘汰赛），并支持一键导出 `.ics`；登录/注册后游客关注会自动合并到账号。竞猜与积分仍需登录。
- **球队积分榜**：「积分榜」页可在「玩家榜 / 球队榜」间切换，球队榜按各小组实时展示排名（场次、胜平负、净胜球、积分），标注出线区与小组第三，并高亮你关注的球队。
- **胜平负竞猜**：对所有**未开赛**的比赛投注（小组赛：主胜 / 平局 / 客胜；淘汰赛：主胜 / 客胜），开赛或录入结果后锁定。
- **赛果录入（管理）**：在「我的 → 赛果录入」中，对已开赛的比赛**录入真实比分以覆盖演示比分**，保存后会实时重新结算积分、并自动推算后续淘汰赛对阵；可一键「恢复演示」。
- **积分与积分榜**：比赛结束（或录入真实比分）后自动结算，猜中一场 +3 分；积分榜对所有用户排名展示，并高亮当前用户。

## 运行

直接用浏览器打开 `index.html` 即可。若浏览器对本地文件有限制，可起一个静态服务：

```bash
cd worldcup2026-h5
python3 -m http.server 8080
# 打开 http://localhost:8080
```

建议用手机或浏览器的「移动设备模拟」模式查看（页面为 H5 竖屏布局）。

## 说明

- 当前日期会决定哪些比赛"已开赛/已结束"，已结束（或已录入真实比分）的比赛才会参与积分结算与淘汰赛对阵推算。
- 小组赛 6 场全部结算后，该组排名确定，对应的淘汰赛槽位（第1/2/3名）会自动填入具体球队；淘汰赛每轮胜者也会自动晋级到下一轮。
- 首次打开会注入几位示例用户，方便直接查看积分榜效果。
- 分组与对阵按官方赛程还原；除官方已赛比分外，未赛比赛展示"模拟比分"（确定性生成，仅用于演示结算），可在「赛果录入」中替换为真实比分。
- 最佳第三名晋级采用候选组约束下的完美匹配算法分配到对应淘汰赛槽位（非 FIFA 官方分配表，但保证对阵可完整解析）。
- 这是演示用前端 Demo：密码以明文存于浏览器本地，请勿用于真实生产场景。
